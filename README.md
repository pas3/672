## Important compatibility notes
- The 6.72 files are kept isolated under `672/`; their exploit engine files are preserved from the supplied archive.
- The main page routes firmware 6.72 to that separate page. Other firmware paths remain separate.
- The 14.00 and 14.02 paths retain their existing firmware-specific source files and patchsets; no offsets or patchsets were copied from 6.72.
- Cache-page history handling and status reporting were adjusted, but actual offline behavior must still be verified in the PS4 browser.
- Source inspection and JavaScript syntax checks are not equivalent to testing on a physical PS4.
